World map: simplified SVG paths generated from Natural Earth 1:110m admin-0 countries.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
License: public domain. https://www.naturalearthdata.com/about/terms-of-use/
Projection: equirectangular, 1000 × 500. Simplification tolerance: 0.35 degrees.
The map is bundled locally and does not send visitor locations to a map provider.
