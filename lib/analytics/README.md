# 区域访客地图

`regional-map.json` 将现有 Natural Earth 国家轮廓投影到东经 72–146°、北纬 0–56°的区域视图，并加入 [Natural Earth 10m 省级轮廓](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/)。该图用于中国、港澳台及周边访问统计，香港与澳门以独立标注显示。

省级 GeoJSON 来源：`nvkelso/natural-earth-vector/geojson/ne_10m_admin_1_states_provinces.geojson`，2026-10-05 获取，原文件 SHA-256 `22d0e3ad85eb3e27f17cabf8ba2d50e554fbc27a87796ff891d958185da62fb5`。几何按 0.07°简化，不用于精确地理定位。地图仍在本地绘制，不向地图服务发送访客数据。
