# 私有访客后台

入口：`/admin/visitors`。后台独立于博客主题，不显示文章导航、外部插件或统计追踪器。登录前不能读取任何访客明细；页面和接口均禁止缓存并标记 noindex。

## 已实现

- 1／7／30 天访问趋势、页面打开次数、匿名访客、会话、平均页面前台停留时间。
- 本地世界地图、IP 推断的大致国家／地区和城市、国家／地区筛选。
- 热门页面、来源网站、设备类别。
- 分页访客列表；按访客查看最近 200 次页面进入的时间、页面、会话、停留、滚动、链接点击次数和最后点击路径。
- 后台使用独立管理密码，scrypt 散列只存放在服务端配置中；签名登录 Cookie 为 HttpOnly、SameSite=Strict，Production 使用 Secure，8 小时过期。修改密码散列会使旧会话失效。
- 登录限制每网络标识 5 次／分钟、20 次／小时。行为接口同源限制、输入验证、独立限流。

## 统计区别

文章及页脚的原有累计计数、访客散列密钥、统计命名空间和 5 分钟去重保持原有规则。后台的“页面打开”每次进入页面产生一条记录，包括刷新，心跳只更新同一条记录，不增加打开数。

会话使用会话存储中的随机标识，30 分钟无活动后新建。浏览器标识沿用现有 localStorage 匿名访客标识。行为采集与文章计数接口分开，不等待行为记录完成才显示文章计数。

停留时长按页面可见时间估算；滚动进度按页面高度估算，不表示读完正文。跳转、关闭、网络失败或浏览器限制会造成部分进度缺失。最多记录单次页面前四小时的进度。

## 保存范围

MongoDB 使用原统计数据库内的独立集合 `visit_analytics_events`，明细保留 90 天；TTL 自动清理，后台查询也显式排除过期数据。累计计数继续保留。URL 查询参数、表单内容、原始 IP、完整 user-agent 和原始浏览器标识不写入明细。来源仅保留网站域名。访客和会话标识使用服务端 HMAC。

地理位置来自 Vercel 请求头 `x-vercel-ip-country`、`x-vercel-ip-city` 等，坐标取一位小数。代理、运营商、CDN 等可能改变位置；缺少平台位置数据时显示“位置未知”，不猜测。

本地地图来自 [Natural Earth](https://github.com/nvkelso/natural-earth-vector)，公有领域数据，无第三方地图服务或定位许可弹窗。

浏览器 DNT／GPC 信号会关闭行为明细记录。公共统计说明为 `/privacy/analytics`，从页脚链接进入。旧累计计数没有访问路径或地理位置，不能回填历史明细。

## Production 配置

继续使用已有统计的 MongoDB、命名空间和散列密钥。新增两个变量，仅 Production：

- `NEXT_PUBLIC_VISIT_ANALYTICS_ENABLE=true`
- `VISIT_STATS_ADMIN_PASSWORD_HASH=scrypt:<32位hex盐>:<128位hex散列>`，Sensitive 类型；不要使用 `NEXT_PUBLIC_` 前缀。

预览环境仍默认禁止连接生产统计库。密码与散列不进入 Git；只在本机保存登录资料并在 Vercel 设置散列。环境变量修改后需要新的部署才会生效。

生成散列时使用 Node.js 内置的 `scryptSync(password, salt, 64)`，其中 `salt` 是 16 个随机字节的 hex 字符串，传入 scrypt 的是此字符串。使用独立、足够长的管理密码。
